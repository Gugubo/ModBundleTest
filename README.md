The goal is to have a single mod that lets you select one out of multiple mods in the options menu.

# Usage
Clone the repo and put the folder in `Spelunky 2\Mods\Packs\` and select the mod in Modlunky.

## Adding a mod to the bundle
Each mod should return a meta table, an activate function, and a deactivate function.
Ideally, if everything is cleaned up correctly, you can cleanly switch between mods.
